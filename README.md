# Student Management System - Feature Branch
## Project Description

Student Management System is a simple web-based application used to add, search, display and delete student records.

## Features

- Add Student
- Search Student
- Display All Students
- Delete Student
- Student ID validation
- Duplicate Student ID checking
- Total Student Count
- Responsive User Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Git
- GitHub

## Project Files

- index.html
- style.css
- script.js
- README.md

## Git Version Control

This project uses Git for:

- Tracking changes
- Creating commits
- Maintaining commit history
- Publishing the project on GitHub+

Open `index.html` in a web browser.
